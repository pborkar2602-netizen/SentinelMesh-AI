Defense in depth

Six layers. No single point of trust.

Each layer is independent, measured, and can be switched off to show what it adds.

01

Taint tracking

Anything an agent reads from outside marks the session as untrusted, and the gateway assigns that label itself. A lying agent cannot clear it.

read_doc(resume.pdf) → session TAINTED
send_email(ext) → BLOCK risk 100
02

Policy gateway

Allow, redact, hold for approval or block, inline.

allow · redact · approve · block
03

Privacy vault

PII is tokenized before logging. Raw access is role-gated and audited.

[EMAIL_1] [PERSON_2]
[SALARY_1]
04

Hash-chained audit

Every decision joins a tamper-evident SHA-256 chain. Change one row and verification fails at that exact event.

0000…a91f → 7c2e…b04d → 51d8…0e3a
chain valid · 10 events verified
05

Learned baseline

Volume, timing and destinations are compared with each agent’s own normal behavior.

rows 9004 vs median 667
anomaly · off-hours · new destination
06

Signed approvals

Privileged actions need a one-time HMAC token bound to the exact action.

forged · expired · replayed · wrong-action
→ all blocked
